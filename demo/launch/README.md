# Putt Print — Launch Demo
Open `index.html` in any browser, or serve it: `npx serve demo/launch` (from /workspace/puttprint).
Arrow keys / Space or the Prev/Next buttons step through 8 screens:
icon → login → courses → setup (ghost + players) → hole play (BEST GHOST ON + PLAY ball) → multiplayer room code → learned clubs → scorecard.
Screens are 1170×2532 captures from the live app. Re-capture: `node tests/launch_capture.cjs` (app on :5174, API on :8787).
